Quy trình chuẩn: Draft → Preview → Publish → Restart → Verify → Nghiệm thu Mọi thay đổi trước Publish chỉ nằm trong `map-tools/projects`; editor không tự dừng hoặc khởi động server.

1. Tạo hoặc Import project

Tạo draft mới: nhập Map ID chưa dùng, tên, kích thước 1–127 ô và Tileset 1–42 rồi bấm Tạo Project.

Import runtime: nhập Map ID đang có. Editor đọc tile/background và `map_template` để tạo bản nháp; chưa sửa dữ liệu đang chạy.

2. Vẽ tile và đặt đối tượng

Chọn công cụ Vẽ/Xóa Tile rồi kéo trên lưới 24px. Khi kéo asset từ palette, bóng kéo và viền xanh trên canvas dùng đúng kích thước x1 mà client hiển thị. Thả ảnh tại góc trên-trái mong muốn, rồi chọn Chọn / kéo để căn trực tiếp.

Dùng L1–L3 cho cảnh phía sau, L4 cho vật che phía trước nhân vật. Có thể bật/tắt từng layer để kiểm tra.

3. Upload PNG chuẩn x4

Chọn PNG, Layer, dx/dy rồi Upload. Kích thước W/H bằng 0 giữ nguyên ảnh nguồn. Hệ thống tự tạo x3 = 75%, x2 = 50%, x1 = 25%; canvas và client thật dùng kích thước x1.

Asset được kéo chính xác từng pixel. Compiler tự chuyển fine offset thành bg_item_template tương thích runtime, nên preview compile và kết quả sau restart giữ cùng vị trí.

4. Chỉnh sửa an toàn

Dùng Undo/Redo hoặc Ctrl+Z, Ctrl+Y. Ctrl+C/Ctrl+V sao chép Asset/NPC/Mob/Điểm chạm; Delete xóa đối tượng chọn; Ctrl+S lưu draft. Khi đã chọn asset, phím mũi tên dịch 1px; Shift + mũi tên dịch 24px.

Resize cho phép chọn anchor. Luôn đọc báo cáo số tile bị cắt và entity bị clamp trước khi chấp nhận.

5. Compile & Preview

Bấm Compile & Preview. Xem Clean để đánh giá hình, Debug để kiểm tra lưới, điểm chạm và entity. Nếu compile báo entity không đứng trên ground hoặc toạ độ vượt biên, quay lại Canvas sửa trước.

JSON dành cho chỉnh nâng cao; không trộn tile-space với pixel-space.

6. Kiểm tra và Publish

Bấm Kiểm tra Publish. Hệ thống chặn khi build cũ, manifest sai, server còn chạy, hoặc thiếu Map/NPC/Mob template tham chiếu.

Khi mọi mục hợp lệ: dừng server, bấm Publish và xác nhận. Publish ghi runtime, DB và tăng `data/map/version.txt` trong một release có backup.

7. Restart và Releases

Khởi động lại server để nạp map. Trong mode Releases, chọn release mới nhất và bấm Verify Runtime + DB. Kết quả phải là KHỚP RELEASE.

Nếu phát hiện drift, không rollback mù. Chỉ rollback release published mới nhất, khi server đã dừng và checksum vẫn khớp.

8. Nghiệm thu trong client

Mở mode Nghiệm thu, chọn release và bấm Kiểm tra lại. Sau khi bốn kiểm tra tự động đều OK, đăng nhập game, đi vào map và thử hình ảnh, collision, cổng, NPC, Mob, asset x1–x4.

Điền người kiểm tra, đánh dấu các mục bắt buộc và Lưu checklist. Chỉ trạng thái SẴN SÀNG NGHIỆM THU mới hoàn tất Giai đoạn 6.

Quy tắc toạ độ cần nhớ

Tile: tileX, tileY × 24px | Asset: ô 24px + fine offset 1px | Player/NPC/Mob/Điểm chạm: pixel tuyệt đối | Kích thước: tối đa 127×127 tile | Layer: L1 → L2 → L3 → Tile → Entity → L4
Khi có lỗi: không sửa trực tiếp file trong `data/map` hoặc SQL release. Quay lại project, tạo revision mới, Compile & Preview rồi Publish thành release mới. Giữ release cũ để đối chiếu/rollback.
